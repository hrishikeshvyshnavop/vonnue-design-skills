# design-knowledge-base

Claude Code skills for the Vonnue design team.

| Skill | Where | What it does |
|---|---|---|
| super-ic-designer | [`SKILL.md`](SKILL.md), [`references/`](references) | High-craft design thinking for UI tasks: discovery, critique, heuristics, personas, handoff |
| screenspec | [`screenspec/`](screenspec/README.md) | Screenshot → Refero-style ScreenSpec → optional blind test → Figma component or local HTML. Also ships as a multi-agent workflow (`screenspec/workflows/screenspec.js`) |

Install a skill by copying or linking its folder into `~/.claude/skills/`. See each skill's README.
